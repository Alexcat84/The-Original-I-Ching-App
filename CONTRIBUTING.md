# Contributing

Thanks for your interest in improving **The Original I Ching App**.

## Before you start

- Open an issue or discuss larger changes first when they affect product behavior, legal copy, or billing.
- Keep changes focused: one concern per pull request when possible.

## Development

- **Web app:** `apps/web` — see that package’s `README` or root `README.md` for install and dev commands.
- **TypeScript:** strict mode; avoid `any` (prefer `unknown` or concrete types).
- **Tests:** run the relevant package tests after substantive changes (e.g. `npm run test` in `apps/web`).

## Pull requests

- Describe **what** changed and **why** in the PR description.
- Match existing code style, naming, and patterns in touched files.
